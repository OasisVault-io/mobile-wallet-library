# rn-multisig-wallet

Library that allows the creation of multisig wallets in BTC and ETH

## Installation

```sh
npm install rn-multisig-wallet
```

## Usage

```js
import { multiply } from "rn-multisig-wallet";

// ...

const result = multiply(3, 7);
```
